# 람지의 여행수첩

여행 중 휴대폰으로 보는 정적 웹사이트예요. 서버·로그인 없이 파일만 올리면 돼요.

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 화면 뼈대 (4개 탭) |
| `css/style.css` | 디자인 |
| `js/app.js` | 동작 (계산, 체크, 필터, 엑셀 등) |
| `data/trip.js` | 여행 이름·날짜·기본 환율 |
| `data/shopping.js` | 쇼핑 리스트 |
| `data/memos.js` | 메모 |
| `images/` | 상품 사진 |
| `design/`, `사진/`, `디자인 참고/` | 작업용 자료 (사이트에는 안 쓰임, 올리지 않아도 됨) |

## 내용 고치기

파일을 고친 뒤 다시 올리면 두 사람 폰 모두에 똑같이 바뀌어요.

각 파일 맨 앞의 `window.SHOPPING =` 같은 부분과 맨 끝의 `;` 는 지우지 마세요. 그 사이 `[ ]` 안이 실제 데이터예요.
쉼표·따옴표가 하나만 틀려도 화면에 "데이터를 불러오지 못했어요"가 떠요. 고친 뒤 `index.html`을 더블클릭해 한 번 확인해 주세요.
아래 예시의 `// …` 설명은 이해를 돕기 위한 것이라 실제 파일에는 적지 않아도 돼요.

### data/trip.js

```js
{
  "name": "후쿠오카",        // 화면 가운데 큰 글씨
  "purpose": "학회",         // 날짜 옆 작은 글씨 (없어도 됨)
  "start": "2026.10.25",
  "end": "10.29",
  "defaultRate": 8.5         // 환율 탭에서 저장하기 전까지 쓰는 기본값
}
```

### data/shopping.js — 상품 하나

```js
{
  "id": "item-13",              // 꼭 서로 달라야 하고, 한 번 정하면 바꾸지 않기 (구매 체크가 여기에 연결됨)
  "store": "무인양품",           // 같은 이름끼리 영수증 한 장으로 묶이고, 위쪽 탭이 됨
  "storeEn": "MUJI",            // 영수증 맨 위 작은 영문 (없어도 됨)
  "name": "Stretch Corduroy Skirt",
  "nameJa": "…",                // 일본어 이름 (없어도 됨)
  "color": "Green",             // 이름 옆 컬러 박스 (없어도 됨)
  "size": "S",                  // 이름 옆 사이즈 박스 (없어도 됨)
  "note": "없으면 23-25",        // ※ 로 표시되는 메모 (없어도 됨)
  "code": "23550307",           // Product Code (없어도 됨)
  "localPrice": 4990,           // 현지 가격, 숫자만
  "krPrice": 49900,             // 한국 가격, 모르면 null
  "photos": ["muji-corduroy-skirt.jpg"]   // images/ 폴더 파일 이름, 여러 장 가능, 없으면 []
}
```

원화 환산 금액과 절약 금액은 적지 않아요. 환율 탭의 고정값으로 자동 계산돼요.

### data/memos.js — 메모 하나

```js
{
  "id": "memo-06",
  "title": "숙소",
  "body": "첫째 줄\n둘째 줄",    // \n 이 줄바꿈
  "color": "lemon",            // lemon / mint / peach / lavender / sky
  "pinned": true               // true 면 맨 앞에 (없어도 됨)
}
```

## 이 폰에만 저장되는 것

환율 고정값, 구매 체크, 가격 표시(원화/현지), 메모 숨김·순서는 각자 폰의 브라우저에 저장돼요.
람지 폰에서 체크해도 남편 폰에는 체크되지 않아요. 브라우저 방문 기록·사이트 데이터를 지우면 함께 지워져요.

## 내 컴퓨터에서 미리 보기

`index.html`을 더블클릭하면 바로 열려요.

## 인터넷에 올리기 (무료)

가장 쉬운 방법은 Netlify Drop이에요.

1. https://app.netlify.com/drop 에 접속해 로그인
2. 이 폴더(`ramzi-pocket`)를 통째로 끌어다 놓기
3. 생긴 주소를 두 사람 폰에 북마크

내용을 고친 뒤에는 같은 사이트의 Deploys 화면에 폴더를 다시 끌어다 놓으면 돼요.
GitHub Pages나 Vercel에 올려도 똑같이 동작해요.
